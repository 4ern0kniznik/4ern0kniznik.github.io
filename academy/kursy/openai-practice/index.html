OpenAI на практике: Responses API, агенты, оценка, MCP

Начать с урока 1 — бесплатно

Первые 2 урока — без входа. С урока 3 — по доступу.

Для кого

  • Для тех, кто автоматизирует рабочие задачи: разбор счетов и заявок, поиск по договорам, отчёты из выгрузок.
  • Для начинающих разработчиков, которые уже пишут на Python простые скрипты и хотят встроить модель в свою программу.

Курс К1 «Промпт-инжиниринг» здесь не повторяем. Как писать саму подсказку — там. Здесь — как отправить её из кода, получить данные в нужной форме и собрать из этого рабочий инструмент.
