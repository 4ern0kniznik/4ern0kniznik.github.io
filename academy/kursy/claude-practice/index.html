Claude на практике: инструменты, навыки, агенты

Начать с урока 1 — бесплатно

Первые 2 урока — без входа. С урока 3 — по доступу.

Для кого

  • Сотрудники, которые автоматизируют свою работу: разбор счетов и заявок, сортировка писем, отчёты из выгрузок.
  • Начинающие разработчики, которым нужно встроить модель в программу.

К5 — следующая ступень после К1 «Промпт-инжиниринг». В К1 задачу ставят в чате. Здесь ту же задачу решает программа: модель вызывает ваши функции, отдаёт JSON, работает по шагам. Приёмы К1 (роль, данные в тегах, примеры, рассуждение) здесь считаются известными.
