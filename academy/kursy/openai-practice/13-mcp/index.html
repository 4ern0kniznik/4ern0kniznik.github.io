Зачем это

В уроках 3 и 10 каждую функцию вы описывали сами и сами выполняли. Если инструментов двадцать и они уже есть у кого-то готовые — у поставщика системы учёта, у сервиса доставки, у базы документов, — описывать их заново долго. MCP (Model Context Protocol) — открытый протокол, по которому сервер сам сообщает модели список своих инструментов и выполняет их. Вы указываете адрес сервера, остальное делает протокол.

Урок держится на платформе OpenAI: встроенный инструмент mcp в Responses API — её возможность. Сам протокол MCP открытый, его поддерживают многие ассистенты и библиотеки.
